# Triple Espresso

## 📝 Descrição do Projeto

O **Triple Espresso** é uma página web desenvolvida como parte do programa de Desenvolvimento Web da TripleTen. O projeto apresenta uma cafeteria fictícia, exibindo informações sobre receitas, canais de contato e um formulário de reserva de mesas.

A página foi construída utilizando **HTML5** e **CSS3**, seguindo rigorosamente a metodologia **BEM (Block, Element, Modifier)** para a organização das classes. Durante a etapa final do desenvolvimento, os estilos foram refatorados em uma estrutura modular de arquivos separados por blocos (dentro do diretório `/blocks`), melhorando significativamente a manutenção, o reaproveitamento e a legibilidade do código.

---

## 🛠️ Tecnologias e Conceitos Utilizados

- **HTML5** (Estruturação semântica e formulários)
- **CSS3** (Estilização avançada)
- **Metodologia BEM** (Organização de classes)
- **Flexbox & Grid Layout** (Alinhamento e posicionamento de elementos)
- **Estrutura modular de arquivos CSS** (Uso de `@import` para gerenciamento de blocos)
- **Normalize.css** (Consistência de renderização entre diferentes navegadores)
